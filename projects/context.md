Gallo Showdown
Gallo Showdown is a C# and XAML game about a young boy who is gifted a rooster and trains it to become the best fighter in the tournament. The game features many unique color variations, with each rooster having attributes that can be built up through training. Players can purchase items in the shop to heal their rooster, treat ailments, and boost performance, and they also receive a daily prize. Players can breed their roosters to unlock new color variations and produce stronger offspring.
I leveraged AI to streamline the idea-to-prototype workflow on this one — using Copilot, Codex, and Claude CLI for building and debugging, and ChatGPT for the artwork. Claude Code handled most of the build and debug cycles alongside Codex. I originally got the idea because I thought it had never been done before, but it turned out it had — I downloaded and played the existing version, and it wasn't great, which gave me confidence to build my own take. The next step is rebuilding it in Unity and deploying it as a mobile multiplayer game.
Agendi
Agendi is a web app I built when I was first learning about ChatGPT's coding capabilities. It uses HTML, CSS, and JavaScript, and runs a small JS server that uses your Canvas API key to view your schoolwork at a glance. I got the idea because I was tired of clicking through every single class just to find my grade, so I built a tool that surfaces everything I needed in one place: current grades, most recent grades, due dates, teacher comments, and grades received, along with the school year, student name, and GPA. The next steps would be adding user profiles, hardening it for safe public use, and then moving into marketing, user testing, and growing the user base.
PTV
PTV is my pride and joy, built in Python. I got the idea while working as a tax prep assistant — I was manually categorizing transactions and knew there had to be a faster way. So I dove head first into Python and built a tool that scrapes data from PDFs, turns it into structured data, and generates reports. Again, I leveraged AI to streamline the idea-to-prototype workflow, then came back to refactor, fix, and add features. The next steps are further debugging, more intuitive features, potentially deploying it as an app, getting users for testing, automating more of the process, integrating AI deeper, and tightening security.

FinBot V1
FinBot V1 was inspired by the original PTV Python script and built using a similar AI-assisted workflow. This first version relied heavily on Claude, which made development fast and efficient and let AI handle much of the categorization and processing. It performed well as a proof of concept, but the biggest challenge was API dependency — after running out of Claude API calls, scalability became limited. The categorization logic also occasionally confused credit and debit statements, which led to inaccurate totals and highlighted reliability issues in the financial calculations.
FinBot V2
FinBot V2 was developed as a spinoff to address the API limitations of V1. This version was rebuilt using Ollama, allowing it to run locally and completely free without external API costs. It's significantly slower than Claude, but the Python script itself was written more effectively, which improved calculation accuracy and overall reliability. AI played a smaller role in this version, with more of the heavy lifting handled directly through Python logic. FinBot V2 showed the tradeoff between speed and automation on one side, and stronger control, stability, and cost efficiency on the other.

My workflow across all of these
I leverage AI to streamline the idea-to-prototype pipeline, then come back to refactor, fix, and add features. I like this approach because it lets the idea come to life quickly — then I can see clearly what parts are working and what parts need real human attention. A strategy I've been using lately is handing off different pieces to peers based on their strengths: some are great at auth and logins, others at frontend, art, security, or backend. AI streamlines the workflow, and the team sharpens it.
